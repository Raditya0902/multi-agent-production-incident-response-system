# Dashboard walkthrough

Start the dashboard with the [local quick start](../README.md#quick-start). Load a sample incident or paste logs and customer complaints, then run diagnosis.

At **Human Approval Required**, review the scope, suggested diff, and confidence signals. Record the run ID if you plan to resume the review after a restart. Approve to test the candidate in the configured sandbox, reject with feedback to regenerate it, or cancel the run.

A successful evaluation can produce incident history, draft replies, and a report. Configured Slack and GitHub integrations may also send a notification or open a reviewable pull request. The sample walkthrough describes the dashboard flow. See the [evaluation reports](evaluation/README.md) for measured outcomes.
